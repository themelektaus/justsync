Edit .ignore Patterns

Pattern Syntax:

  • /Test.txt - File in root only
  • Test.txt - Any file named Test.txt
  • /Test/ - Folder in root
  • *.txt - All .txt files
  • /Test/*.txt - All .txt in Test folder
  • /Test/**/*.txt - All .txt in Test and subfolders
  • # comment - Comment (ignored)
